此文件记录第一轮数据接入阶段。第一关实现后的场景、脚底镜像锚点与验证状态以 CHAPTER01_README.md 和 CURRENT_GAME_RULES.md 为准。

日期：2026-11-08。本轮仅使用当前项目 docs，不访问旧 Phaser 项目或源码。

## 来源与状态

实际读取 LEVEL_DESIGN_SPEC.md、LEVEL_SCALE_REFERENCE.svg（完整 XML 和文本标注）、GAME_RULES.md、DEVELOPMENT_PROGRESS.md；检查了当前 Assets 文件清单、ProjectVersion.txt、Packages/manifest.json。docs 另有 LEVEL02_TEST_REPORT.md、LEVEL_ARCHITECTURE_REVIEW.md，仅列出，未作为参数来源。

“已确认”指规格文档记载的旧实现常量，本轮没有重新审计或运行旧源码；也不意味着 Unity 手感已验证。当前 Unity 为6000.3.28f1，原 Assets 没有游戏 C# 脚本。

## PPU 与坐标

采用 **100 PPU** 作为本轮统一配置方案（工程选择，不是旧文档确认常量）。1px=0.01世界单位，速度和加速度均除以100，ms除以1000。保留精确原始px数值作为唯一数据源，派生世界值，不对齐网格或重定角色尺寸。

参考画幅1280×720、16:9，对应12.8×7.2单位；正交相机 size=3.6。适配应保持该视野比例，必要时留边；正式横向地图总长度独立于画幅，尚无数值。未修改相机或屏幕设置。

参考坐标左上原点，x向右、y向下；Unity世界原点对应参考(0,0)，转换为`(x/100,-y/100)`。参考矩形左上转Unity矩形左下为`(x/100,-(y+h)/100)`。角色用中心锚点；脚底为Unity中心y减0.19。Sprite导入须统一100 PPU，Transform保持单位缩放；目前没有新增美术或更改导入设置。

## 配置使用

唯一数值来源：`Assets/Resources/Configuration/GameParameters.json`。`Assets/Scripts/Configuration/GameParameters.cs`显式`GameParameters.Load()`读取，提供只读世界单位属性、坐标转换、理论高度；消费者共享加载后的实例。不得在控制器、相机、箱子和材质脚本另设回退默认值。未来若采用Rigidbody2D，应明确选定重力施加方式，避免项目重力与自定义-14重复叠加；本轮不选择运动实现。

PPU是明确标注的工程方案，其余JSON值来自规格的已确认参数。材质和箱子参数仅作后续参考接入。尚未确定的数据不置零充当正式值；后续关卡数据须独立定义世界边界、指定轴、固定入口列表及检查点列表。本轮不创建入口/地图/测试房间，不修改现有场景或ProjectSettings。
