# Chapter01 / 第一章「留白」· 首段「初染」

第二段现扩展在同一场景右侧，连续游玩、无文字正式画面及连接穿界说明见LEVEL02_UNITY.md。本文件以下保留第一关原始交付记录。

2026-11-08。只开发第一关；未访问旧 Phaser 项目。

## 打开与操作

1. 使用 Unity 6000.3.28f1 打开此项目，等待脚本编译和资源导入完成。
2. Project 窗口双击 `Assets/Scenes/Chapter01.unity`，或菜单 `YiChiLanRan → Open Chapter01`。
3. 点击 Play，点击 Game 视图使其获得键盘焦点。
4. A/D或左右箭头移动，Space跳跃，S/下箭头在空中冲跃，R从蓝态起点重新开始。

无需拖拽脚本、设置碰撞层或手动搭建地形。场景已通过Editor API保存，Build Settings已登记Chapter01。若场景或生成资源被自行移除，可在停止Play后使用`YiChiLanRan → Build Chapter01`生成；此命令会覆盖生成资源，人工改动前请先提交版本。

通关：从左侧走到莲花标记上方，跃起后按S冲跃，变为白态。向右跳上50px小台阶，接近下伸高墙左侧时起跳跨过110px凹谷；右侧旗杆是检查点。继续向右，经过60px凹处后再跳上右侧平台，抵达出口旗标。首段完成后可继续走到预留右边界，不切换场景。跌入深谷自动回已激活恢复点。

## 尺寸与统一来源

`GameParameters.json`是运动与尺度唯一来源；100 PPU，1px=0.01u，y向上。角色显示及碰撞0.28×0.38u、中心到脚底0.19u，单位缩放；水平2.6u/s，重力-14u/s²，刚性/蓝弹性/回弹起跳5.2/6.5/7.9u/s，下落限速6.2u/s，冲跃-10.5u/s；保持文档参数。采用文档120Hz物理节拍，实际由运动控制器显式积分并进行连续轴向AABB扫掠，不依赖项目Physics2D重力，不叠加额外刚体重力。

参考视野1280×720、12.8×7.2u、正交size3.6；窗口保持16:9并留黑边。镜头只横向跟随，y=-3.6。地图参考宽1800px/18u；有效轮廓x=40–1800px（17.6u），基础上下边界y=150–640px（4.9u高）。这是未来连续地图的首段，长度是新关卡设计值，不是原Demo常量。

`Chapter01.json`保存单份轮廓、轴、入口数组、出生/检查点/出口及失败阈值。蓝色矩形从轮廓向下生成，白色互补矩形从顶边到同一轮廓生成，没有第二份手工地图。

## 镜像与入口

轴为基础世界y=-3.95（参考395px），与入口表面明确分开。地形矩形中心`(cx,cy)→(cx,2b-cy)`，尺寸不变，纹理flipY同步。角色**脚底中心**作统一锚点：向下扫到入口平面，精确求接触脚底，再反射，最后加0.19u求正立中心。不对角色中心另外做反射，不加安全落位偏移。

入口范围参考x=180–300px、y=450px，即世界x=1.8–3.0、y=-4.5，中心(2.4,-4.5)；镜像后y=-3.4。脚底(2.4,-4.5)严格映射至(2.4,-3.4)，角色中心由(2.4,-4.31)变为(2.4,-3.21)。允许双向冲跃，要求整个人物宽度处于有效范围。`CrossingPoint.prefab`是可复用标记与入口组件，每个实例可配置范围和基准表面；本关只放一个。

蓝白两种互补地形始终显示。按正式同色碰撞规则启用对应颜色Collider；高墙没有被删除或隐藏，两色矩形均按同一公式反射。运动控制器扫掠读取的Rect与BoxCollider2D的位置、尺寸一致；不会通过放宽人物碰撞体绕过墙。

## 文件职责

- `Assets/Scripts/Configuration/GameParameters.cs`、`Assets/Resources/Configuration/GameParameters.json`：集中参数及单位转换。
- `Assets/Resources/Configuration/Chapter01.json`、`ChapterData.cs`：首段数据结构和数值。
- `ClothPlayer.cs`：键盘、输入缓冲、宽限、重力、冲跃、碰撞、回弹。
- `ChapterWorld.cs`：整图镜像、安全几何检查、进度/恢复点、镜头和简洁HUD。
- `TerrainPiece.cs`、`CrossingPoint.cs`、`ClothArt.cs`：实体几何、固定入口和配色。
- `Assets/Editor/Chapter01Builder.cs`：通过Unity API创建场景、Prefab、独立程序化布纹/花叶/人物贴图和URP Unlit材质。
- `Assets/Editor/Chapter01Smoke.cs`：一次基本自动通关；只在编辑器执行，直接使用正式角色控制器，无独立测试房间。
