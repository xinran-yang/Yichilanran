# 《一尺蓝染》Unity 2.1 / 2.2 Codex 开发策划

完整图文版请参阅同名 DOCX；以下为机器可读的关键规则和任务。

## 核心不变量
- 角色仅与同色对象发生普通实体碰撞，特殊机关可例外。
- 每次有效传送都使整个地图（地形、所有箱子、机关位置）上下镜像；箱子颜色不会因镜像本身变化。
- 黄色：只传人物，人物换色，箱子颜色不变。
- 绿色：可单独传人物，箱子颜色不变；或通过同色箱子位于转移区且被角色从上方 Dive 命中时带箱转移，仅参与箱子换色。
- 玩家始终正立，左右控制不反向。传送需目标空间安全检查与防重复触发。
- 新版箱子为正方形，高度为人物的约 1.2–1.4 倍（待实测），玩家能跳上；不得沿用旧版 96×130 的长方形。

## 2.1 标准解
1. 蓝人踩蓝箱①上平台。
2. 黄色：人物蓝→白，地图及三箱镜像，箱色不变。
3. 推白箱②垫脚，沿镜像后白色可走的中层路线到绿色区。
4. 推白箱③进入绿色区，从上方 Dive 命中。
5. 绿色带箱：人物白→蓝，箱③白→蓝，地图与其他箱子镜像但其他箱色不变。
6. 踩蓝箱③到旗帜。

## 2.2 标准解
1. 黄色：蓝人→白人，地图与箱镜像，箱色不变；不可直达绿色②。
2. 绿色①单人：白→蓝，地图与箱镜像；蓝箱①仍蓝。
3. 左平台推下蓝箱①，使其可参与绿色①带箱转移。
4. 绿色①带箱：蓝人→白人，箱①蓝→白，箱②③不变色；箱②镜像后自动填坑。
5. 推白箱①通过箱②填补的坑，借箱①抵达右侧白箱③。
6. 绿色②带箱：白人→蓝人，箱③白→蓝；借蓝箱③上终点。

## 2.2 四个硬约束
1. 第一次黄色后不能直接到绿色②。
2. 箱②镜像后自动填坑，坑宽与新版正方形箱宽匹配，箱①可通过。
3. 顶部设人可过、箱不可过的竖直限箱障碍，阻止直接推箱②跳关。
4. 初始状态箱③上方空间不足以跳越，必须完成必要镜像才能推箱③到位。

## 开发架构
PlayerController2D、PhaseCollisionSystem、WorldMirrorSystem、TransferZone2D、TransferBox2D、LevelDefinition、LevelReset、GoalTrigger、DebugOverlay。

## 任务顺序
先只读检查旧 Phaser 源码及 Unity 项目，列出映射与风险；再通用机制→2.1 灰盒→2.2 灰盒→物理/跳关验收→视觉动画。不得凭手绘图杜撰精确坐标。

## 旧版参考参数（不是 Unity 直接赋值）
1280×720；人物 28×38 px；水平 260 px/s；重力 1400 px/s²；普通跳 520 px/s；蓝弹跳 650 px/s；冲跃 1050 px/s；固定步长 120Hz；旧版矩形镜像 y′=790−y−h。
