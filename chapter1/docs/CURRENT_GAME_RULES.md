# 《一尺蓝染》当前正式机制

生效日期：2026-11-08。依据本轮用户确认；与历史文档冲突时以本文件为准。本文定义目标规则，不代表 Unity 已实现玩法。

## 正式规则

1. 仅设计师设置的固定穿界点允许切换，可以设置多个。普通蓝白交界线不允许随意穿越。
2. 角色在合法穿界点向下冲跃触发切换；普通跳跃、自然落地、地面按下不触发切换。
3. 整张基础地图沿指定水平轴上下镜像，所有左右位置保持不变；不是只翻转当前屏幕。
4. 根据第一关开发指令，角色以**脚底中心**为统一几何映射锚点，相对指定水平穿界轴严格轴对称：`footX'=footX, footY'=2a-footY`，Transform中心=`foot'+(0,角色半高)`，并切换 BLUE ↔ WHITE。角色始终正立，左右操作不反转，不对角色使用负 Y 缩放。这取代上一轮的中心锚点约定；不得声称角色中心也同时满足反射公式。
5. 矩形地形在左上角、y 向下的参考坐标中为 `x'=x, y'=2a-y-h`；Unity 的 y 向上坐标采用相同反射关系，矩形应按中心反射。
6. 使用连续横向卷轴地图，设置检查点。1280×720 是参考画幅，不是正式地图总尺寸。
7. 后续支持箱子、尖刺、蓝色弹性、白色脆裂；当前仅接入已有参考参数，不表示这些机制已实现。

## 继承的设计参考

蓝白互补区域保持可见，同色和中性实体参与普通碰撞。蓝色弹性起跳与冲跃回弹为不同速度，回弹固定、不叠加；白色普通行走/落地不碎，主动冲跃局部碎裂。穿界应先于同处材质反馈结算，避免一次冲跃同时换态和破坏落点。以上来自 GAME_RULES.md，尚未在 Unity 验证。

## 尚未冻结的细则

- 第一关轴确定为参考y=395px，Unity世界y=-3.95；入口参考x=180–300px/y=450px。多个入口的数据结构已经支持，本关仅放一个，整图共用轴。
- 第一关在脚底向下扫过合法界面时求精确接触点，再严格反射脚底。整个人物宽度须在入口范围内；换态时速度归零并采用已有120ms恢复，取消当前冲跃，地面不允许触发。没有安全出口平移、居中或额外2px偏移。若反射后碰撞不安全，拒绝并报告几何错误。
- 第一关穿界瞬时完成，无复杂翻转动画；相机只横向跟随、不翻转。未来动画和跨区轴策略仍待定。

- 箱子严格转移关系、多箱行为、尖刺尺寸/判定、破坏状态跨态保存、正式通关条件未冻结。
