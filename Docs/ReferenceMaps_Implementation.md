# 新参考图关卡与支撑镜像

## 当前规则与上一轮修正

上一轮仅保证了镜像提交瞬间的坐标，但所有箱子恢复同一向下运动，未保存支撑关系，不能复现用户希望的效果。旧 Phaser 明确停用异色箱子的物理，并对同色箱重新找落点；前者已复用，后者不符合严格镜像要求，没有沿用。

用户本轮确认：蓝人踩蓝路、推蓝箱；白人踩白路、推白箱。同色箱翻到平台下侧后仍保持原支撑关系，并可沿下侧推动。

当前通用实现：

- 箱子中心与平台中心统一使用 newY=2*mirrorAxis-oldY，所有颜色和参与状态的箱子都变换；只有绿色参与箱换色。
- 保存接触的平台 ID 与支撑侧，镜像时支撑侧翻转。支撑有效时约束 Rigidbody2D 的 Y，X 仍由正常推动与碰撞处理。支撑是接触关系，不是最近地面搜索，不会修改箱子目标坐标。
- 异色箱暂停模拟，保持可见和严格位置；同色箱开启模拟。没有反转全局或人物重力。箱子推离平台边缘后释放支撑并正常下落，着地后可获取新的接触支撑。
- 有支撑时 body.gravityScale=0、额外垂直加速度=0；无支撑的活动箱使用原来的向下加速度。人物继续向下运动。
- 黄色与绿色共用 WorldMirrorSystem。绿色按箱子上侧/下侧对应的接触面判断入区，不为关卡 ID 写镜像分支。
- 人物安全落位、颜色过滤、目标重叠拒绝及切换期间的统一物理锁定保留。

## 先打开最小场景

`Assets/_Game/Scenes/MirrorInspection.unity` 已生成，仅有一块平台、一个箱子和一个黄色点。人物在此作为不受力的观察者，方便反复检查；这不是正常关卡的操控方式。

- T：执行一次黄色世界切换。
- C：仅在此检查场景切换观察者颜色，检查同色倒挂箱也能保持支撑。
- A/D：直接给可交互箱子横向调试输入，观察平台下侧移动；不会开启在正式关卡中的远程推箱能力。
- F3：打印最近镜像审计和实时坐标/物理状态。
- R：复原。

Console 筛选 `[MirrorAudit]`、`[MirrorState]`、`[MirrorBoxLive]`、`[MirrorTerrainLive]`。LevelRuntime 的 LastMirrorAudit 也保留逐箱记录。

实测基准：镜像轴6，箱子中心(9,4.02)↔(9,7.98)，平台中心(11,3.25)↔(11,8.75)。实际 Play Mode 连续切换5次，每次等待正常物理帧后垂直漂移0；箱色保持蓝。异色 simulated=false，同色 simulated=true；两种状态均保留同一支撑ID。另测同色箱下侧横移通过，Y不漂移。完整记录见 DevReports/SupportMirror-Minimal.txt 与 SupportMirror-Coordinates.csv。
